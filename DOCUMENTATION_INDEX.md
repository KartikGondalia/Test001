## 🔑 Key Concepts

### Google Drive Integration
- Photos are stored in a Google Drive folder
- Admin uploads photos to Drive (not in-app)
- App fetches photos from Drive using Google Drive API
- Photos cached in Firestore for real-time updates
- All users see same photos from admin's Drive folder
- **Details**: See [GOOGLE_DRIVE_INTEGRATION_SUMMARY.md](GOOGLE_DRIVE_INTEGRATION_SUMMARY.md)

### Data Flow
- Admin uploads → Google Drive folder
- App syncs → Google Drive API
- Caches in → Firestore database
- Users see → Real-time in app
- **Details**: See [GOOGLE_DRIVE_UPDATE_SUMMARY.md](GOOGLE_DRIVE_UPDATE_SUMMARY.md)

### Authentication
- Users sign in with Google account
- App gets OAuth token
- Token used to access Drive & Firestore
- Role-based access control via Firestore rules
- **Details**: See [GOOGLE_DRIVE_SETUP.md](GOOGLE_DRIVE_SETUP.md)

## 🚨 Important Notes

### ⚠️ Before Running the App
1. Configure Firebase credentials
2. Create Google Drive folder
3. Set up OAuth credentials in Google Cloud Console
4. Update Firestore security rules
5. Get Drive folder ID and update in app

### ⚠️ Before Deploying
1. Update admin email in Firestore rules
2. Test on both iOS and Android
3. Upload test photos to Drive
4. Verify photos appear in app
5. Check all error scenarios
6. Update privacy policy
7. Prepare app store descriptions

### ⚠️ OAuth Scopes Required
```
https://www.googleapis.com/auth/drive.readonly
https://www.googleapis.com/auth/drive.file
```

### ⚠️ Firestore Collections Needed
```
photos_cache - Caches Drive photos
videos - YouTube video data
admins - Admin user data
```
